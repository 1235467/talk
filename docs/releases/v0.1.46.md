# Talk v0.1.46

本次版本重点补齐了地点地图 MVP，并把联系人生成改造成可持续运行、可恢复的后台任务。

## 地点地图

- 地图改为铺满可视区域，默认镜头对准当前位置，支持拖动、缩放与一键回到当前位置。
- 新增精绘临江市背景，以及现代河城、日式、美式、英式、法式、维也纳、中世纪、古代中式、原始部落、奇幻和赛博朋克共 11 套地图主题。
- 新增 40 余种地点图标，并支持导入自定义图标和自定义地图背景。
- 支持创建、编辑、移动和删除用户地点；地点详情会展示当前在场角色的头像与姓名。
- 地图生成器升级为结构化地形系统，加入河流、海岸、城区、乡村、山地、道路和桥梁关系；旧地图由用户确认后再升级。
- 地形图例收纳为浮动图层入口，减少对地图主体的遮挡。

## 联系人生成

- 联系人创建改为持久化后台任务，离开页面后仍可继续生成。
- 新增任务进度、阶段状态和流式字段预览；生成中断后可继续、重试、暂停、取消或删除。
- 新增更完整的错误诊断与复制功能，方便定位模型、网络或响应格式问题。
- 联系人列表和名片页可直接查看对应生成任务及其状态。

## 使用模式与稳定性

- 新增“沉浸模式”和“自由模式”，分别面向开箱即用体验与完整自定义能力。
- 新增增量 JSON 解析，使模型尚未输出完毕时也能安全展示已完成字段。
- 数据库、备份恢复、设置与功能模块同步支持新的生成任务和体验模式。
- 补充地点地图、联系人生成、增量解析和关键回归测试。

## 下载说明

- Android：提供 debug 签名 APK，可直接安装测试；它不是应用商店正式签名包。
- Windows：同时提供安装版和便携版 EXE。
- 安装包不内置开发者的 API Key，请在应用设置中填写自己的模型服务配置。
